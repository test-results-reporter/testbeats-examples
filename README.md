# TestBeats Examples

This repository demonstrates how to integrate various testing frameworks with [TestBeats](https://testbeats.com) - a test reporting and analytics platform.

## 📋 Overview

TestBeats helps you:
- Publish test results to various channels (Slack, Teams, etc.)
- Generate visual test summaries with charts
- Track CI/CD information alongside test results
- Centralize test reporting across multiple frameworks

## 🧪 Supported Frameworks

### Current Examples
- [Cypress](./cypress/README.md) - E2E testing framework integration
- [Java + TestNG](./java-testng/README.md) - Java TestNG with Selenium WebDriver integration
- [Playwright](./playwright/README.md) - Playwright E2E testing with TestBeats integration
- [Cucumber PactumJS](./cucumber-pactumjs/README.md) - Cucumber with PactumJS API testing
- [WebDriverIO + Cucumber](./webdriverio-cucumber/README.md) - WebDriverIO with Cucumber E2E integration

### Coming Soon
More framework integrations will be added to this repository.

## 🚀 Quick Start

Each framework integration is in its own directory with:
- Sample tests
- Configuration files
- GitHub Actions workflow
- Detailed README with setup instructions

Navigate to the specific framework directory to get started:
```bash
# For Cypress
cd cypress

# For Java + TestNG
cd java-testng

# For Playwright
cd playwright

# For Cucumber PactumJS
cd cucumber-pactumjs

# For WebDriverIO + Cucumber
cd webdriverio-cucumber
```
